## Evidence rules

- **Implemented and verified**: item-specific acceptance exists within the stated scope; not production approval.
- **Already implemented and verified**: acceptance confirmed existing behavior rather than a new implementation.
- **Implemented but awaiting integrated acceptance**: isolated branch evidence exists, but shared ancestry does not include it.
- **Partially complete**: only part of the requirement has evidence.
- **Blocked by policy**: a reviewed contract/decision is required.
- **Not yet verified**: source/tracker claim exists without sufficient item acceptance.
- **TODO**: no accepted completion established here.
